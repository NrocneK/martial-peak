# Prompt tạo icon kỹ năng (52 icon)

## Cách dùng
1. **Đính kèm ảnh mẫu phong cách** (8 icon AI trong game: kiếm, đao, quạt, bí bảo, đan, đan lô, linh thạch).
2. Có icon kỹ năng đầu tiên ưng ý rồi thì **đính kèm thêm icon đó** khi tạo các icon sau → 52 icon đồng bộ.
3. Mỗi lần tạo **1 icon**, chép nguyên khối prompt của icon đó (đã gồm phần phong cách chung + mô tả riêng).
4. AI chỉ vẽ hình bên trong, **không vẽ khung**: khung (vuông / vàng thức tỉnh / bát giác bị động) mình thêm bằng code.
5. Đặt tên file ảnh theo cột **Tên file** (vd `ngu_kiem.png`, `ngu_kiem_aw.png`) rồi gửi mình.
6. Chỉ Ngân Hà Hàn Lưu / Thiên Hà Băng Phong là kỹ năng băng. Icon nào vẽ sai với kỹ năng trong game → gửi mình sửa mô tả.
